## Asset provenance and limits

- Figma: https://static.figma.com/app/icon/2/icon-256.png, linked by the official Figma homepage.
- Retool: https://dqpcjghenxt8u.cloudfront.net/images/sanity/retool-favicon-light-128x128.svg, linked by the official Retool homepage.
- Supabase: https://supabase.com/favicon/favicon-196x196.png, linked by the official Supabase homepage.
- Power BI: the Microsoft product icon URL is retained exactly from its official product page.
- Tableau: the official favicon https://www.tableau.com/c/public/exp/app/favicon.ico is retained. Tableau was absent from the inspected current Simple Icons slug registry; no replacement path was invented.
- Visual Studio Code: https://code.visualstudio.com/assets/branding/code-stable.png was observed as an image link on https://code.visualstudio.com/brand and opened through the web reader. Microsoft's guidance allows an icon link to its official website and restricts uses implying association. Keep the icon linked to the official product and do not use it as a MoreSpace partnership badge.
- Other software icons: names and slugs were verified against https://github.com/simple-icons/simple-icons/blob/develop/slugs.md and use its documented CDN pattern https://github.com/simple-icons/simple-icons#cdn-usage. These are authentic brand-reference SVGs maintained by Simple Icons, rather than invented artwork or generic favicon proxies.

In the prior Windows environment, an ordinary official-PNG download failed at the configured proxy. Nothing was bypassed, and no image bytes were preserved there. That historical result is not a claim about the current Linux environment. The recovered dataset itself contains remote URLs, so local asset retrieval, rendering, and Figma import remain separate verification steps.
